# 看懂一句

一个极简的考研英语理解训练网站。页面随机展示一句或一小段英文，用户从四个中文选项中选择最准确的理解，并立即查看解析。

在线地址：<https://ally1212.github.io/kaoyan-english/>

## 功能

- 40 道原创或改写的考研风格理解题
- 点击“选择词库”后，通过弹出的书架式封面选择“全部 / 基础 / 进阶 / 挑战”四种训练词库
- 每轮随机训练 5 题，并整理最多 10 个生词；内置题库每轮固定 10 词
- 每轮结束后重新洗牌，不连续重复同一道题
- 点击选项后立即判定并显示简短解析
- 保存当前题目、答题数和正确数到浏览器本地
- 只使用 `WASD` 键位，依次对应第一、第二、第三、第四个选项
- 生词提示在桌面端位于正文右侧，在手机端排列于正文和选项之间
- 支持逐个或一次性展开本题生词拆解
- 点击生词旁的“在线词典”后，补充音标、词性、英文释义、例句和发音
- 启动时获取在线题库，失败时自动回退到缓存或本地题库
- Enter 进入下一题
- 适配桌面和手机浏览器

## 数据说明

答题记录只保存在当前浏览器的 `localStorage` 中，不会上传。清除浏览器数据或点击页面中的“重新开始”会删除记录。

用户主动点击“在线词典”时，页面会把对应的英文单词发送给 Free Dictionary API 查询；不会发送题目、中文选项、答题结果或其他个人数据。

### 训练词库

当前40道题按照理解难度分成三个水平：

- 基础：13题，侧重常见否定、转折、条件和词义辨析
- 进阶：19题，侧重比较结构、因果限制、多因素判断和段落主旨
- 挑战：8题，侧重倒装、否定转移、复杂推断和条件迁移
- 全部：混合使用以上40题

页面平时只显示当前词库和“选择词库”入口。点击后才会弹出书架，用户通过书本封面切换词库，选择完成后书架自动关闭，并开始一轮新的随机训练。答题数和正确率从0重新计算。每轮包含5道题，内置题库每题提供2个生词，因此一轮正好整理10个生词。选择结果保存在浏览器中，下次打开网站仍会使用上次选择的水平。

如果远程题库某轮不足5题，页面会按实际题数完成该轮；如果生词总量不足10个，页面也只展示真实存在的词，不会重复或虚构内容。

题量来自当前实际加载的题库，并非写死。如果远程题库缺少某个水平，对应按钮会自动禁用。

### 在线题库

默认地址是 `/question-bank.json`。开发服务器会直接提供该接口，生产构建也会生成同名 JSON 文件，其中包含当前的 40 道题和 80 个生词条目。

加载顺序：

1. 获取在线题库并校验数据结构
2. 联网失败时使用上次成功缓存的题库
3. 缓存也不可用时使用打包在网站中的本地题库

如需让题库脱离网站代码独立更新，复制 `.env.example` 为 `.env.local`，配置远程 JSON 地址：

```bash
VITE_QUESTION_BANK_URL=https://example.com/question-bank.json
```

远程服务器需要允许浏览器跨域读取该文件。JSON 中每道题需要包含 `id`、题型、难度、标签、英文、四个中文选项、答案、解析和生词数组。完整结构可直接参考开发服务器返回的 `/question-bank.json`。

执行 `npm run build` 后，也可以直接将 `dist/question-bank.json` 上传到 GitHub Raw、Cloudflare R2 或其他静态文件服务。

### 在线词典

网站使用开源的 [Free Dictionary API](https://dictionaryapi.dev/)：

- 不需要账号、API Key 或付费套餐
- 浏览器可直接跨域调用
- 返回音标、词性、英文释义、例句和部分单词的发音
- API 代码采用 GPL-3.0；返回内容携带 Wiktionary 来源与 CC BY-SA 许可信息，页面会原样显示来源链接
- 查询结果会在浏览器缓存 30 天，最多保存 100 个词，减少重复请求
- 请求超时、接口不可用或没有收录时，不影响本地中文拆解和答题

对于短语，页面会自动选择最有信息量的核心词查询。例如 `be attributed to` 会查询 `attributed`。在线结果最多展示三条释义，保持页面简洁。

如需改用自己部署的兼容接口，可配置：

```bash
VITE_DICTIONARY_API_URL=https://api.example.com/entries/en
```

#### 为什么没有直接使用其他开源词库

- [ECDICT](https://github.com/skywind3000/ECDICT) 有大量英汉释义和考试标签，适合后续自建后端，但它提供的是 CSV/SQLite/MySQL 数据与 Python 接口，不是可供纯前端直接调用的公共 API。
- [Wiktionary API](https://en.wiktionary.org/api/rest_v1/) 可以直接调用，但定义中包含 HTML，音标与发音需要额外解析；Free Dictionary API 已经把这部分整理成更简单的 JSON。
- [FreeDict](https://freedict.org/) 提供可自由使用的离线双语词典，其中英汉词典约 2.6 万词条，但主要发布为下载数据包，不提供面向浏览器的公共查询 API。

Free Dictionary API 是公益公共服务，没有正式 SLA。当前实现因此坚持“按需查询、浏览器缓存、失败不阻塞”的策略；如果网站流量显著增长，建议自托管该 API 或将 ECDICT 做成自己的只读接口。
