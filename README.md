# 看懂一句

一个极简的英语考试词汇与阅读理解训练网站。用户先选择考试词库和训练类型，再通过四选一题目完成每组 5 题训练；系统随后自动整理错题并进行一次针对性自测。

在线地址：<https://ally1212.github.io/kaoyan-english/>

## 功能

- 四级、六级、考研、雅思参考、托福参考五种考试词库
- 单词认义、英文释义、句意理解三种训练类型
- 80 道人工整理的考研风格题，加 1,200 道开放中英句意题
- 每完成 5 道普通题自动进入本轮复盘
- 自测优先使用本轮错题，并补入同一词库和类型下当天到期的历史错题
- 错题按 1 天、3 天、7 天间隔复习，第三次复习正确后标记为已掌握
- 开放句意题按相对质量优先抽取，用户也可将问题题目降权并随时撤销
- 点击选项后立即显示正确答案、音标、词性、中英文释义或阅读解析
- `W`、`A`、`S`、`D` 依次对应第一至第四个选项，`Enter` 进入下一步
- 阅读题继续支持逐个或全部展开生词提示
- 在线词典按需补充发音、更多释义和例句
- 适配 320px 起的手机竖屏、手机横屏、小平板、刘海安全区和动态浏览器工具栏，并支持 `prefers-reduced-motion`

## 怎么理解“词库”和“训练类型”

两者是独立概念：

- **考试词库**决定练哪些单词，例如四级或考研。
- **训练类型**决定怎么练，例如选择中文词义或直接判断英文释义。
- **基础 / 进阶 / 挑战**只用于考研阅读题的难度筛选，不再被称为词库。

句意理解已对五种考试开放。考研训练同时包含人工整理的考研风格题和开放例句；其他考试使用按照对应考试词汇覆盖筛选的开放例句。开放例句用于基础句意识别，不等同于考试真题。

## 词汇数据

词汇数据来自 MIT 许可的 [ECDICT](https://github.com/skywind3000/ECDICT)，当前固定快照为：

```text
bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b
```

网站只保留同时具有中文释义和英文释义的可训练词条：

| 词库 | 可训练词数 |
|---|---:|
| 四级 | 3,846 |
| 六级 | 5,403 |
| 考研 | 4,801 |
| 雅思参考 | 5,019 |
| 托福参考 | 6,952 |

同一个单词可以带有多个考试标签，因此实际联合词表是 10,641 个词，而不是五个数量简单相加。完整许可说明见 [third-party-notices.md](./public/third-party-notices.md)。

这些数量代表 ECDICT 考试标签中同时具有中英文释义的可训练词条，不代表官方完整大纲。全国大学英语四、六级考试 2016 年修订版词表共收录 5,418 个词目；考研英语大纲通常表述为约 5,500 个单词。两类官方大纲词表与开源词典标签的统计口径不同。

## 句意语库

句意训练由两层内容组成：

| 内容层 | 数量 | 用途 |
|---|---:|---|
| 人工考研题 | 80 | 训练否定、转折、比较、推理等考研阅读结构 |
| Tatoeba / ManyThings 开放例句 | 1,200 | 扩大五种考试的基础句意识别覆盖 |

开放例句来自 CC BY 2.0 FR 许可的 Tatoeba 中英句对，经过去重、长度筛选、简繁转换和 ECDICT 词汇覆盖筛选。每道题都保留原始句子编号、贡献者署名、许可链接和改编说明。自动生成的生词内容明确标记为词典参考义，需要结合整句判断。当前覆盖量：四级 538、六级 437、考研 546、雅思参考 1,096、托福参考 325；同一道题可以属于多个考试，因此不能直接相加。

开放例句的“基础 / 进阶 / 挑战”是当前语库内部按句长划分的相对难度，不代表考试官方等级。当前三档分别有 815、319、66 题，五种考试的每一档都至少可以组成一轮 5 题训练。

生成器会综合词汇覆盖、句长、干扰项长度、难度接近程度和考试标签重叠度，为 1,200 道开放题给出 55 到 95 的库内相对质量分。排名前 500 道显示为“精选例句”并提高抽取概率，其余题目仍然保留用于扩大覆盖。这个分数只用于同一语库内部排序，不是人工审校分，也不代表考试真题质量。

完成一道普通句意题后，可以点击“题目有问题”。该题仍保留在题库中，但下一轮出现权重会降低到原来的 5%；再次点击即可撤销。反馈只保存在当前浏览器中，不会上传。

## 每 5 题自测

一轮固定为 5 道普通题：

1. 系统记录本轮答错的题目。
2. 第五题后显示错误答案、正确答案和错题数量。
3. 自测先放入本轮错题，再补入同一考试和训练类型下当天到期的历史内容，最多 5 题。
4. 自测结束后展示详细解析，以及“明日复习 / 3 天后复习 / 已掌握”等下一步状态。
5. 如果本轮全对但存在历史待复习内容，仍会进入历史复习；两者都没有时才显示通过卡片。

错题状态分为“待复习 / 巩固中 / 已掌握”。答错后立即可复习；前三次复习答对后分别安排到 1 天、3 天、7 天后，其中第三次答对即标记为已掌握。任何一次再次答错都会回到待复习。

## 联网与回退

人工题库、开放语库和考试词库都使用相同的三级加载原则：

```text
在线 JSON → 浏览器 HTTP 缓存 / 小型校验缓存 → 打包的本地保底数据
```

- 阅读题默认读取 `/question-bank.json`。
- 开放语库默认读取 `/sentence-bank.json`。
- 考试词汇默认读取 `/vocabulary-bank.json`。
- 完整联合词库约 2.2MB，gzip 传输约 700KB。
- 超过 1MB 的完整语库和词库不再写入 `localStorage`，避免挤占答题进度和错题记录空间；静态资源仍可使用浏览器 HTTP 缓存。
- 本地保底包含 305 个去重核心词和 72 道分层开放例句，网络失败时五种考试的三档难度仍都可以完成一轮训练。
- 错题记录会去重并保留最近 500 条，避免长期训练无限占用浏览器存储。
- Free Dictionary API 只用于用户主动点击后的补充查询，失败不会阻塞答题。

如需让数据脱离网站独立更新，可复制 `.env.example` 为 `.env.local`：

```bash
VITE_QUESTION_BANK_URL=https://example.com/question-bank.json
VITE_SENTENCE_BANK_URL=https://example.com/sentence-bank.json
VITE_VOCABULARY_BANK_URL=https://example.com/vocabulary-bank.json
VITE_DICTIONARY_API_URL=https://api.dictionaryapi.dev/api/v2/entries/en
```

远程服务器需要允许浏览器跨域读取 JSON。

远程句库的每道题必须提供 HTTPS 来源链接、许可名称、许可链接、作者署名和改编说明；远程数据会经过字段长度、响应大小和超时校验，失败时自动回退。

## 更新 ECDICT 快照

先下载 ECDICT 的 `ecdict.csv`，然后运行：

```bash
node scripts/generate-vocabulary-bank.mjs /path/to/ecdict.csv
```

脚本会重新生成：

- `public/vocabulary-bank.json`：完整联合词表
- `src/data/vocabularyFallback.ts`：五种考试的本地高频保底词

更新快照时还需要同步检查脚本内的 ECDICT commit、README 词数和第三方许可说明。

## 更新开放句意语库

从 [ManyThings](https://www.manythings.org/anki/) 下载 `cmn-eng.zip`，解压后运行：

```bash
node scripts/generate-sentence-bank.mjs /path/to/cmn.txt
```

脚本会生成完整的 `public/sentence-bank.json` 和离线保底 `src/data/sentenceFallback.ts`，并通过 `opencc-js` 将繁体中文转换为简体中文。

## 隐私

训练进度、词库选择、错题记录和题目质量反馈只保存在当前浏览器的 `localStorage` 中，不会上传。

用户主动点击“在线词典”时，只会发送当前英文单词，不会发送题目、选项、正确率或错题记录。查询结果在浏览器缓存 30 天，最多保留 100 个词。

## 部署

推送到 `main` 分支后，GitHub Actions 会运行测试、类型检查和生产构建，再将 `dist` 发布到 GitHub Pages。
